Система управления данными студентов

Актуальность проекта

Автоматизация учёта студентов позволяет упростить хранение и обработку информации, сократить время выполнения расчётов и уменьшить количество ошибок.

Цель проекта

Разработать консольное приложение на языке C++ для управления данными студентов и их успеваемостью.

Задачи проекта

1. Реализовать добавление студентов.
2. Реализовать просмотр списка студентов.
3. Добавить поиск студентов по идентификатору.
4. Реализовать изменение и удаление данных.
5. Добавить ввод и хранение оценок.
6. Реализовать расчёт среднего балла.
7. Обеспечить сохранение и загрузку данных из файла.

Основные функции

- Добавление, просмотр, поиск и удаление студентов.
- Редактирование информации.
- Управление оценками.
- Автоматический расчёт среднего балла.
- Сохранение данных.

Целевая аудитория

Преподаватели, сотрудники образовательных учреждений и студенты.

Технологии

- Язык программирования: C++
- Система контроля версий: Git
- Платформа: GitHub
- Тип приложения: консольное

Запуск программы

Для запуска программы необходимо:

1. Установить Microsoft Visual Studio с поддержкой C++.
2. Открыть проект StudentManagement.slnx.
3. Скомпилировать проект.
4. Запустить программу сочетанием клавиш Ctrl + F5.
5. Выбрать нужное действие в консольном меню.

Данные студентов сохраняются в файле students.txt
и загружаются при следующем запуске программы.
